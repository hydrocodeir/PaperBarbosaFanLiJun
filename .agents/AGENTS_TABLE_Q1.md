# AGENTS_TABLE_Q1.md

## Role

Design and audit scientific tables for Q1-level manuscripts.

Tables should present precise information more efficiently than prose or figures.

---

## Table Necessity

Before creating a table ask:

- Does the reader need exact values?
- Are many variables/groups compared?
- Would a figure communicate the pattern better?
- Is this information already reported elsewhere?

Do not duplicate figures in table form without scientific reason.

---

## Structure

A strong table should have:

- concise title;
- logical rows;
- logical columns;
- units;
- consistent decimals;
- clear abbreviations;
- meaningful footnotes.

---

## Numerical Precision

Use scientifically justified precision.

Do not report:

- unnecessary decimal places;
- inconsistent rounding;
- false precision.

Maintain consistent decimals within comparable columns.

---

## Units

Put units:

- in headers;
- in variable labels;
- or in a clearly defined footnote.

Do not repeat units in every cell unless necessary.

---

## Statistical Tables

When appropriate include:

- estimate;
- uncertainty;
- confidence interval;
- p-value;
- effect size;
- sample size.

Define all statistical symbols.

---

## Missing Values

Represent missing values consistently.

Distinguish:

- not measured;
- not applicable;
- missing;
- below detection;
- unavailable.

Do not use blank cells ambiguously.

---

## Significance Markers

If significance letters or symbols are used:

- derive them from actual analysis;
- define the test;
- define adjustment method;
- define alpha threshold.

Never invent grouping letters.

---

## Abbreviations

Define nonstandard abbreviations in notes.

Do not overload the table with unexplained shorthand.

---

## Table-to-Text Consistency

Cross-check every key value cited in manuscript text.

No value should differ between:

- table;
- Results;
- Abstract;
- Discussion;
- Conclusion.

## Table Formatting

When a target journal is known, follow its style.

Otherwise prefer:

- minimal rules;
- no decorative shading unless useful;
- no excessive vertical lines;
- aligned decimals where possible;
- concise headings.

---

## Non-Negotiable Rules

1. Never invent values.
2. Never change values to make formatting easier.
3. Never hide missing data.
4. Never mix units silently.
5. Never duplicate a figure without a reason.
6. Never use significance notation unsupported by analysis.
